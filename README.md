# 🏰 Medieval India - UPSC Preparation

Interactive flashcards and quiz application for UPSC Medieval India preparation.

## 📚 Topics Covered

### Early Medieval Period
- **Gurjara Pratiharas** (730-1036 CE)
  - 18 flashcards covering dynasty history, rulers, administration, culture
  - 15 quiz questions with detailed explanations

## 🚀 Features

- **Multi-Topic Navigation**: Home menu → Topic selection → Learning modes
- **Interactive Flashcards**: Flip cards to learn key concepts
- **Browse Mode**: View all content at once
- **Quiz Mode**: Test knowledge with multiple-choice questions
- **Progress Tracking**: Track mastery with localStorage persistence
- **Mobile Responsive**: Works on all devices

## 🛠️ Tech Stack

- React + Vite
- CSS3 (responsive design)
- localStorage (progress tracking)
- GitHub Pages (deployment)
